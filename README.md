## Blueprint Summary

| Aspect | Detail |
|--------|--------|
| **What** | AI-native ERP for Indian businesses |
| **Who** | Indian companies ₹1-500 Cr revenue (SaaS, e-commerce, trading, services) |
| **Why** | No AI-native ERP exists for India. Tally is desktop-only. Zoho has no real AI. Campfire/Rillet don't do GST. |
| **Moat** | GST/TDS/e-invoicing native + WhatsApp + Hindi AI + 80x cheaper + self-serve |
| **Tech** | Next.js + Fastify + PostgreSQL + DeepSeek/GPT-4o + AWS Mumbai |
| **Timeline** | Phase 1 (MVP): 4 months, Phase 2 (Growth): 8 months, Phase 3 (Scale): 12 months |
| **Team** | Start with 5-6 devs in India, grow to 12-14 |
| **Cost to build** | ~₹5-6L/mo (Phase 1) → ~₹12-14L/mo (Phase 3) |
| **Revenue target** | 1,000 paying customers by Month 12 → ~₹30-50L MRR |
